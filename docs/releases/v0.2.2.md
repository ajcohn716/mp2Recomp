# mp2Recomp v0.2.2

Alpha update: invite Steam friends from Netplay and accept invitations during
play. Matching installers and dependency packs are included for Linux and
Windows x86-64.

## Changes

- Add **Invite friends** to unstarted Steam rooms. The host sees only Steam
  friends currently playing **Spacewar (App ID 480)**, with paging and refresh.
  Friendship and game activity are checked again when sending an invitation.
- Show incoming invitations during offline and online games, with **Accept**
  and **Dismiss** controls. Accepting leaves the current game or room and joins
  the invited lobby; it does not carry current game progress into that room.
- Initialize the Steam helper asynchronously when the graphical game launches.
  Recipients do **not** need to open Netplay or host a room to be invitable.
  Steam must be running and signed in, and game activity must be visible.
- Use private Steam matchmaking lobbies for invitation delivery, and retain the
  existing authenticated Steam P2P protocol for game traffic. Invite lobbies
  close when the host starts or leaves. Late joining remains unsupported.
- Share one standalone helper between invitations and Steam networking, add
  protocol-2 compatibility checks, and allow retrying initial Steam failures.
  Offline and Direct TCP games still work without Steam.

## Upgrade

Download the installer archive for your platform, extract the complete archive,
and keep its included SDK archive compressed beside the installer. Run it and
select your existing installation directory to preserve saves and settings.
Each player supplies their own supported, unmodified Mario Party 2 USA ROM.

Upgrade the game and its Steam helper together. The v0.2.1 protocol-1 helper
and dependency packs are incompatible with v0.2.2; use the matching new pack.
No Steamworks SDK or development headers are needed by players.

## Validation and limits

Local Linux validation covered the full native build, settings controls and
rendered invitation panels, the shared helper protocol and retry behavior,
real Steam friend filtering and private lobby creation, real UDP connection
callbacks and reliable messaging, and four Direct TCP game processes with
1,200 matching input/RNG/checkpoint frames.

Delivery and acceptance between separate Steam accounts/home networks still
need validation. A full graphical smoke test under Xvfb was blocked by Vulkan
presentation support. Windows game boot, cross-platform Steam play, complete
boards/minigames, and long sessions remain unverified. This is an experimental
alpha; disconnects and detected desynchronization stop the session.

No ROM, generated game code, or game assets are distributed. The standalone
Steam helper remains MIT-licensed; the game and installer remain
GPL-3.0-or-later. Valve's runtime retains Valve's terms. Source archives,
matching dependency packs, license notices, and checksums accompany installers.
