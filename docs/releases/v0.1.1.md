# mp2Recomp v0.1.1

Installer and Linux runtime fixes for v0.1.

## Fixes

- Fix unreadable white-on-white text in the Windows installer. Text and
  backgrounds now use a complete palette, with contrast checks for light and
  dark system palettes.
- Include the font configuration and XKB keyboard data needed by the Linux
  runtime. The executable locates these files in its installation directory,
  including after moving that directory, without depending on build-machine
  paths or manual environment variables.
- Remove the installer slogan.
- Add a runtime-data self-test for GTK, Fontconfig and XKB, and regression tests
  for missing data, relocation and installer text contrast.

## Installation and upgrade

Download `mp2recomp-installer-linux-x86_64.tar.gz` or
`mp2recomp-installer-windows-x86_64.zip`. Extract the archive and keep the
included SDK archive beside the installer executable, still compressed.
Run the installer, select your Mario Party 2 USA ROM and installation directory,
and press **Go**. To upgrade, select the existing game installation directory;
saves and settings are preserved. The earlier Linux environment-variable
workaround is no longer required after reinstalling with this version.

No ROM, game assets or generated game code are included. The matching
integration source, SDK dependency packs and SHA-256 checksums are attached.

## Validation and limits

The corrected Linux installation was tested through the title screen with
working audio and settings. Windows and Linux installer tests, palette contrast
checks and frozen GUI/CLI startup checks passed in GitHub Actions. Runtime-data
checks exercise missing and relocated configuration data without a ROM.

This remains a boot/title proof of concept with experimental netplay. Full-game
play, long sessions and actual Windows game boot still need further validation.
See [the README](https://github.com/ajcohn716/mp2Recomp/blob/v0.1.1/README.md)
and [netplay documentation](https://github.com/ajcohn716/mp2Recomp/blob/v0.1.1/docs/netplay.md)
for setup and known limitations. Runtime dependencies retain their own licenses.
