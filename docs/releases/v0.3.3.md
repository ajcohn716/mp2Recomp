# mp2Recomp v0.3.3

This release restores the v0.3.1 gameplay and controller behavior and fixes
online play between Windows and Linux. The two downloads now share a netplay
build ID. Every player in the room should update to v0.3.3.

Download and extract the archive for your platform. Copy your existing
`userdata/` folder into the new folder to keep your saves, settings, and cached
ROM. Open `./play` on Linux or `mp2recomp.exe` on Windows.

The Windows build is unsigned. Smart App Control may block it on some Windows
11 PCs.
