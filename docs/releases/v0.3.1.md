# mp2Recomp v0.3.1

The portable game now detects your unmodified Mario Party 2 USA ROM in a
`games/` folder beside the executable. Create the folder, put your `.z64`,
`.v64`, or `.n64` file directly inside it, and open `./play` on Linux or
`mp2recomp.exe` on Windows. The game accepts any filename and opens the ROM
picker if it still needs a ROM.

Pressing **Escape** during play now opens a quit confirmation. Select **Quit**
to exit or **Cancel** to keep playing.

Download and extract the archive for your platform. To upgrade, copy your
existing `userdata/` folder into the new folder to bring over saves, settings,
and the cached ROM. The game requires a Vulkan-capable graphics driver.

The Windows build is unsigned. Smart App Control may block it on some Windows
11 PCs.
