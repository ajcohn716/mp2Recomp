# mp2Recomp v0.3.0

Download the prebuilt game for Linux or Windows x86-64. Extract it into a
writable folder, open `./play` on Linux or `mp2recomp.exe` on Windows, and
select your own unmodified Mario Party 2 USA ROM. You can play as soon as
the game validates your ROM.

- The portable download contains the game executable and its runtime libraries.
  The compiler and SDK are used on the release build machine.
- The ROM picker accepts `.z64`, `.v64`, and `.n64` files and stores a local copy
  for later launches. To upgrade, copy `userdata/` from your previous install
  into the extracted folder to bring over saves, settings, and the cached ROM.
- The executable includes the recompiled game and audio code. Players supply
  their own ROM. The release includes the host integration source and checksums.

The game requires a Vulkan-capable graphics driver. This is an experimental port.
The Windows build is unsigned. Smart App Control may block it on some Windows 11
PCs.

The [v0.2.3 release](https://github.com/ajcohn716/mp2Recomp/releases/tag/v0.2.3)
provides the source installer for players who prefer to compile locally.
