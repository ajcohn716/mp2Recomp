# mp2Recomp v0.1

Initial public proof-of-concept release, including experimental room netplay.

## Downloads and installation

- **Linux x86-64:** download `mp2recomp-installer-linux-x86_64.tar.gz`.
- **Windows x86-64:** download `mp2recomp-installer-windows-x86_64.zip`.

Extract the archive and keep the entire directory intact. Launch
`mp2recomp-installer` (Linux) or `mp2recomp-installer.exe` (Windows), drop your
own Mario Party 2 USA ROM into the window, choose an installation directory,
and press **Go**. The matching SDK is included for offline installation.
No Python, compiler or development packages need to be installed separately.
A Vulkan-capable graphics driver is required.

The supported 32 MiB US ROM has SHA-1
`166eda1c05670d337e2c3f15a5db528ae1e5d6e3`; `.z64`, `.v64` and `.n64` byte
orders are accepted. No ROM, assets or generated game code are distributed.
SHA-256 sidecars are provided for installer archives.

## Included

- Native static CPU recompilation with N64ModernRuntime and RT64 graphics.
- Boot through the opening sequence to the title screen.
- Keyboard/controller bindings, hotplug support and persistent audio settings (F1).
- Experimental encrypted room netplay for two to four players. Start with
  `--netplay`; the host forwards TCP port 7777 and shares the generated connection
  code. Each participant needs their own ROM and the same release.
- Separate netplay session saves; offline saves are preserved.
- Self-contained Linux and Windows installers and SDKs built by GitHub Actions.
- Authored source licensed under GPL-3.0-or-later.

See [netplay setup](https://github.com/ajcohn716/mp2Recomp/blob/v0.1/docs/netplay.md) and [the README](https://github.com/ajcohn716/mp2Recomp/blob/v0.1/README.md) for controls,
source builds and detailed validation.

## Known limitations

This is an early proof of concept. Complete boards/minigames, long sessions,
separate home networks and Linux/Windows cross-play need further validation.
Netplay uses direct host connections with no relay or matchmaking; the host
must be reachable. Rollback, late joins and reconnection are not implemented.
Connection codes grant access to a room and must be shared privately.
Some title prompt glyphs appear as blocks. Actual Windows game boot remains
unverified; Windows compilation, installer and transport checks run in CI.

GitHub's source downloads and the integration source archive do not contain a
ROM or generated game code. Runtime dependencies retain their own licenses;
see [third-party notices](https://github.com/ajcohn716/mp2Recomp/blob/v0.1/THIRD_PARTY_NOTICES.md).
