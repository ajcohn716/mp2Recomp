# mp2Recomp v0.2.3

Installer update fixing Windows dependency-cache failures caused by long file
paths. Matching installers and freshly rebuilt dependency packs are included
for Linux and Windows x86-64.

## Changes

- Fix SDK extraction, checksum verification, cache publication and dependency
  source copying when Windows' system long-path policy is disabled. This
  addresses `No such file or directory` errors for deeply nested filenames
  under `mp2recomp-cache/dependencies`.
- Remove unused SPIRV-Cross shader regression inputs and reference outputs from
  the SDK, including the long `overlapping-bindings` filename reported by users.
  Compiler sources, build files and license notices remain included.
- Apply the same source-copy filtering when preparing a local build. Downloaded
  and manually selected offline SDK archives use the same fixed extraction path.
- Add regression tests for long cache paths, cache reuse, source copying, UNC
  path conversion and preservation of required sources and licenses. Release
  packaging also tests the actual Windows SDK with `LongPathsEnabled=0`.

## Upgrade

Download the new installer archive for your platform and extract it completely.
Keep its included SDK archive compressed beside the installer. Run the new
installer and select your existing installation directory to preserve saves
and settings. Use the matching v0.2.3 SDK; older SDK packs do not match this
release's runtime recipe. No Windows registry change is required for the fixed
SDK extraction and source-copy operations.

Each player supplies their own supported, unmodified Mario Party 2 USA ROM.
This update retains v0.2.2's game behavior and protocol-2 Steam helper. Windows
game boot, cross-platform Steam play, complete boards/minigames and long
sessions remain unverified. This is an experimental alpha.

No ROM, generated game code or game assets are distributed. The standalone
Steam helper remains MIT-licensed; the game and installer remain
GPL-3.0-or-later. Valve's runtime retains Valve's terms. Source archives,
matching dependency packs, license notices and checksums accompany installers.

See the [installation guide](https://github.com/ajcohn716/mp2Recomp/blob/v0.2.3/docs/installation.md).
