# mp2Recomp v0.2.1

Alpha installer update: Steam multiplayer support is included on Windows and
Linux x86-64. Players no longer need a Steamworks SDK or a separate source build.

## Changes

- Bundle a precompiled standalone Steam networking helper and Valve's platform
  runtime library in each installer dependency pack.
- Start the helper automatically when entering a Steam room. Offline and Direct
  TCP play continue to work without Steam installed or running.
- Keep SDK headers private to the build process. Installation still generates
  and compiles game code locally from the user's ROM.
- License the independent helper and its shared transport/protocol headers
  under MIT. The game, installer, and upstream GPL dependencies retain their
  existing licenses. Valve's runtime retains Valve's terms.
- Validate the helper's file allowlist, hashes, and source recipe during
  packaging and installation, and update setup and multiplayer documentation.

## Install and play

Download `mp2recomp-installer-windows-x86_64.zip` or
`mp2recomp-installer-linux-x86_64.tar.gz`, extract the whole archive, and keep the
included SDK archive compressed beside the installer. Put your unmodified
Mario Party 2 USA ROM beside the installer for automatic detection, or select
it manually. Choose your installation directory and press **Go**. Upgrading in
the same directory preserves saves and settings.

For Steam multiplayer, install Steam separately, run it and sign in, then open
**F1 → Netplay → Steam**. Each player needs their own Steam account and computer.
This alpha uses the Spacewar test App ID 480. Steam may show the game as Spacewar.
Share the connection code privately; Steam rooms need no TCP port forwarding.
Keep the installed helper and runtime files together when moving the game.

## Alpha validation and limits

Checks focus on compilation, packaging, helper protocol startup, and installing
the bundled helper without SDK headers. Local Linux checks initialized the real
Steam client and created a listener through the separate helper. This release
does not claim cross-account/home-network Steam sessions, Windows game boot,
Linux/Windows cross-play, complete boards/minigames, or long-session validation.

No ROM, game assets, or generated game code are distributed. Source, SDK packs,
license notices, and SHA-256 checksums accompany the installers. See the
[installation guide](https://github.com/ajcohn716/mp2Recomp/blob/v0.2.1/docs/installation.md),
[multiplayer guide](https://github.com/ajcohn716/mp2Recomp/blob/v0.2.1/docs/netplay.md),
and [helper documentation](https://github.com/ajcohn716/mp2Recomp/blob/v0.2.1/docs/steam-helper.md).
